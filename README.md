# Дипломный автопроект — Яндекс Лавка

## Цель

Автоматизировать небольшой критический путь сервиса:

**каталог → корзина → оформление заказа → проверка данных**

Проект объединяет UI, API, DB-check, Allure, изоляцию данных и CI.

## Набор проверок

1. API: создание пользователя.
2. API: создание корзины с товарами.
3. API: добавление товара в существующую корзину и проверка содержимого.
4. API: оформление заказа и проверка заказа пользователя.
5. DB-check: после создания заказа проверить запись в `order_model`.
6. UI: открыть каталог и добавить товар в корзину.
7. UI: оформить заказ и проверить успешное завершение.

## Запуск

```bash
pip install -r requirements.txt
playwright install chromium
```

Создайте `.env` на основе `.env.example`.

```bash
pytest
```

Allure:

```bash
pytest --alluredir=allure-results
allure serve allure-results
```

## Переменные

- `BASE_URL` — адрес стенда.
- `API_URL` — API-адрес. Если не задан, используется `BASE_URL`.
- `PRODUCT_ID` — товар для API-тестов.
- `DB_TABLE_ENDPOINT` — endpoint для проверки таблиц БД через API.

## Важно

UI-локаторы вынесены отдельно в `ui/locators.py`.
Если HTML стенда изменился, исправлять локаторы нужно только там.
